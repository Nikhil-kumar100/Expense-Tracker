
# 💰 Expense Tracker & Analytics Dashboard

A personal expense tracking and analytics dashboard built with Python and Streamlit. Track income and expenses, analyze spending, and visualize financial data.

## 🚀 Features

- Add income and expense transactions
- Dashboard with Income, Expense and Net Savings
- Date and Category filters
- Monthly Income vs Expense chart
- Expense and Savings percentage analysis
- Search transactions by category or description
- Export filtered transactions to CSV and Excel
- Recent transactions view

## 🛠️ Tech Stack

- Python
- Streamlit
- Pandas
- SQLite
- OpenPyXL

## 📂 Project Structure

    Expense_Tracker/
    ├── app.py
    ├── database.py
    ├── expense.py
    ├── main.py
    ├── requirements.txt
    └── .gitignore

## ▶️ Run Locally

1. Clone the repository.
2. Install dependencies:

       pip install -r requirements.txt

3. Run the application:

       streamlit run app.py

## 📊 Project Overview

This project helps users track their income and expenses and understand their financial activity through an interactive dashboard, filters, charts, and downloadable reports.
